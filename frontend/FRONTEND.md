# climb-you Frontend

ChatGPT Apps SDK を使用したフロントエンド実装

## 構造

```
frontend/
├── src/
│   ├── components/      # UIコンポーネント
│   ├── hooks/          # カスタムフック
│   ├── utils/          # ユーティリティ関数
│   ├── types/          # TypeScript型定義
│   ├── styles/         # スタイル
│   └── App.tsx         # メインアプリ
├── public/             # 静的ファイル
└── package.json
```

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
