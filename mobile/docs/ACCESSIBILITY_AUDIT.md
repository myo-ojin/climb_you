## 知覚可能（Perceivable）

情報とユーザーインターフェイスコンポーネントは、ユーザーが知覚できる方法で提示される必要があります。

### 1.1 テキストの代替（Text Alternatives）

- [x] **1.1.1 非テキストコンテンツ（A）**
  - すべてのアイコン、画像、ボタンに `accessibilityLabel` が設定されている
  - 装飾的な画像は `accessibilityElementsHidden={true}` が設定されている
  - ステータスアイコン（✅、⏭️、🚧、◯）にテキスト説明がある

### 1.3 適応可能（Adaptable）

- [x] **1.3.1 情報および関係性（A）**
  - セマンティックな `accessibilityRole` を使用（button, header, text, etc.）
  - リスト構造が適切にマークアップされている（FlatList）
  - フォーム入力に `accessibilityLabel` とヒントがある

- [x] **1.3.2 意味のある順序（A）**
  - スクリーンリーダーの読み上げ順序が論理的
  - `accessibilityViewIsModal` で適切にフォーカスを制御

- [x] **1.3.3 感覚的な特徴（A）**
  - 色だけでなく、アイコンやラベルで情報を伝達
  - 難易度表示: 色のドット + テキストラベル
  - クエストタイプ: 色のバッジ + テキストラベル

- [x] **1.3.4 画面の向き（AA）**
  - ポートレートとランドスケープの両方をサポート

- [x] **1.3.5 入力目的の特定（AA）**
  - 入力フィールドに `textContentType` を設定（iOS）
  - `autoCompleteType` を設定（Android）

### 1.4 判別可能（Distinguishable）

- [x] **1.4.1 色の使用（A）**
  - 色だけでなく、アイコンやテキストで情報を伝達
  - `checkColorDistinguishability` ユーティリティで検証

- [x] **1.4.3 最低限のコントラスト（AA）**
  - 通常テキスト: 4.5:1以上
  - 大きなテキスト: 3:1以上
  - HighContrastテーマで7:1以上を実現

- [x] **1.4.4 テキストのサイズ変更（AA）**
  - 200%までのテキストサイズ変更をサポート
  - `ScaledText` コンポーネントで動的テキストサイズに対応
  - `useDynamicTextSize` フックで自動スケーリング

- [x] **1.4.10 リフロー（AA）**
  - 320px幅でコンテンツが正しく表示される
  - 横スクロールが不要

- [x] **1.4.11 非テキストのコントラスト（AA）**
  - UIコンポーネントの境界線: 3:1以上
  - フォーカスインジケーター: 3:1以上
  - ハイコントラストモードで2pxボーダー

- [x] **1.4.12 テキストの間隔（AA）**
  - 行間: 1.4倍以上（`ScaledText` で自動調整）
  - 段落間隔: 適切に設定

- [x] **1.4.13 ホバー時またはフォーカス時のコンテンツ（AA）**
  - ツールチップやポップオーバーが適切に実装されている
  - フォーカス時にコンテンツが隠れない

## 操作可能（Operable）

ユーザーインターフェイスコンポーネントとナビゲーションは操作可能である必要があります。

### 2.1 キーボード操作可能（Keyboard Accessible）

- [x] **2.1.1 キーボード操作（A）**
  - すべてのインタラクティブ要素がフォーカス可能
  - スクリーンリーダーのスワイプジェスチャーで操作可能
  - `accessible={true}` が適切に設定されている

- [x] **2.1.2 フォーカストラップなし（A）**
  - モーダル内でフォーカスが適切に制御されている
  - `accessibilityViewIsModal` を使用

- [x] **2.1.4 文字キーのショートカット（A）**
  - 文字キーのショートカットは無効化または変更可能
  - （モバイルアプリでは該当なし）

### 2.2 十分な時間（Enough Time）

- [x] **2.2.1 タイミング調整可能（A）**
  - 時間制限のある操作は調整可能
  - クエストの有効期限は明示的

- [x] **2.2.2 一時停止、停止、非表示（A）**
  - 自動更新コンテンツは一時停止可能
  - アニメーションはモーション低減設定を尊重

### 2.3 発作と身体反応（Seizures and Physical Reactions）

- [x] **2.3.1 3回の閃光または閾値以下（A）**
  - 1秒間に3回以上の閃光を含むコンテンツなし
  - アニメーションは滑らかで予測可能

- [x] **2.3.3 インタラクションからのアニメーション（AAA）**
  - モーション低減設定で不要なアニメーションを無効化
  - `useReduceMotion` フックを使用
  - `adjustAnimationDuration` で継続時間を0msに調整

### 2.4 ナビゲーション可能（Navigable）

- [x] **2.4.1 ブロックスキップ（A）**
  - ナビゲーションスキップリンクを提供
  - 各画面のメインコンテンツに直接アクセス可能

- [x] **2.4.2 ページタイトル（A）**
  - 各画面に明確なタイトルがある
  - `navigation.setOptions({ title: '...' })` を使用

- [x] **2.4.3 フォーカス順序（A）**
  - フォーカス順序が論理的で一貫している
  - スクリーンリーダーで自然な順序で読み上げられる

- [x] **2.4.4 リンクの目的（コンテキスト内）（A）**
  - すべてのボタンとリンクに明確な `accessibilityLabel`
  - リンク先が明確

- [x] **2.4.7 フォーカスの可視化（AA）**
  - フォーカス時に視覚的なフィードバック
  - `TouchableOpacity` の `activeOpacity` を使用
  - ハイコントラストモードで強調表示

### 2.5 入力モダリティ（Input Modalities）

- [x] **2.5.1 ポインタのジェスチャ（A）**
  - 複雑なジェスチャーには代替手段を提供
  - Pull-to-Refreshは標準的なジェスチャー

- [x] **2.5.2 ポインタのキャンセル（A）**
  - タップ操作はリリース時に実行される
  - `TouchableOpacity` のデフォルト動作

- [x] **2.5.3 ラベル内の名前（A）**
  - `accessibilityLabel` が表示テキストを含む

- [x] **2.5.4 モーションによる起動（A）**
  - デバイスの動きによる機能には代替手段がある
  - （該当する機能なし）

- [x] **2.5.5 ターゲットのサイズ（AAA）**
  - タッチターゲットサイズ: 44x44pt以上
  - `MIN_TOUCH_TARGET_SIZE` 定数で管理
  - `ensureTouchTargetSize` で自動調整
  - `checkTouchTargetSize` でテスト検証

## 理解可能（Understandable）

情報とユーザーインターフェイスの操作は理解可能である必要があります。

### 3.1 読みやすさ（Readable）

- [x] **3.1.1 ページの言語（A）**
  - 主要言語が日本語として識別される
  - `accessibilityLanguage="ja-JP"` を設定

- [x] **3.1.2 一部分の言語（AA）**
  - 英語の略語には適切な読み方を提供
  - （該当箇所少ない）

### 3.2 予測可能（Predictable）

- [x] **3.2.1 フォーカス時（A）**
  - フォーカス時に予期しない動作が発生しない

- [x] **3.2.2 入力時（A）**
  - 入力時にコンテキストが変更されない

- [x] **3.2.3 一貫したナビゲーション（AA）**
  - ナビゲーションが全画面で一貫している
  - React Navigationで統一的な遷移

- [x] **3.2.4 一貫した識別（AA）**
  - 同じ機能を持つコンポーネントは一貫したラベル

### 3.3 入力支援（Input Assistance）

- [x] **3.3.1 エラーの特定（A）**
  - エラーメッセージが明確
  - `accessibilityLiveRegion` でエラーを通知

- [x] **3.3.2 ラベルまたは説明文（A）**
  - すべての入力フィールドにラベル
  - `accessibilityLabel` と `accessibilityHint` を使用

- [x] **3.3.3 エラー修正の提案（AA）**
  - エラー時に修正方法を提示

- [x] **3.3.4 エラー回避（法的、金銭的、データ）（AA）**
  - 重要な操作には確認ダイアログ
  - クエスト完了/スキップに確認

## 堅牢（Robust）

コンテンツは、支援技術を含む様々なユーザーエージェントによって確実に解釈できる必要があります。

### 4.1 互換性（Compatible）

- [x] **4.1.1 構文解析（A）**
  - React Nativeコンポーネントが適切に構成されている
  - TypeScriptで型安全性を確保

- [x] **4.1.2 名前、役割、値（A）**
  - すべてのUIコンポーネントに適切な `accessibilityRole`
  - `accessibilityLabel` と `accessibilityHint` が設定されている
  - `accessibilityState` でステータスを伝達

- [x] **4.1.3 ステータスメッセージ（AA）**
  - ステータス変更時に `announce` でスクリーンリーダーに通知
  - `accessibilityLiveRegion="polite"` を使用

## テスト環境

### iOS
- **デバイス**: iPhone 12以降推奨
- **OS**: iOS 15.0以降
- **スクリーンリーダー**: VoiceOver
- **動的テキスト**: 設定 > アクセシビリティ > 画面表示とテキストサイズ > さらに大きな文字
- **ハイコントラスト**: 設定 > アクセシビリティ > 画面表示とテキストサイズ > コントラストを上げる
- **透明度を下げる**: 設定 > アクセシビリティ > 画面表示とテキストサイズ > 透明度を下げる
- **視差効果を減らす**: 設定 > アクセシビリティ > 動作 > 視差効果を減らす

### Android
- **デバイス**: Pixel 4以降推奨
- **OS**: Android 10以降
- **スクリーンリーダー**: TalkBack
- **フォントサイズ**: 設定 > ユーザー補助 > フォントサイズ
- **表示サイズ**: 設定 > ユーザー補助 > 表示サイズ
- **ハイコントラストテキスト**: 設定 > ユーザー補助 > ハイコントラストテキスト
- **アニメーションの削除**: 設定 > ユーザー補助 > アニメーションの削除
