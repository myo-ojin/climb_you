# climb-you モバイルアプリ版（React Native）開発ロードマップ

## 概要

本ロードマップは、climb-youのReact Nativeモバイルアプリケーション（iOS/Android対応）の開発計画を定義する。4つのフェーズに分けて段階的に実装し、各フェーズで動作確認とテストを実施する。Windows環境での開発を前提とし、Expo + React Nativeを使用する。

```

                                  ────────────────────
                                  合計: 12週間（約3ヶ月） ※調整中
```

## リスクと対策

### 技術的リスク

**リスク1: iOS実機テストの制限**
- 対策: Expo Goアプリで開発中のプレビューを活用
- 代替案: macOSを持つチームメンバーに実機テストを依頼、またはEAS Buildでビルドして実機テスト

**リスク2: バックエンドAPI未完成**
- 対策: モックデータで先行開発
- 代替案: ローカルのみで動作するバージョンを先に完成

**リスク3: ストア審査リジェクト**
- 対策: 審査ガイドラインの事前確認
- 代替案: TestFlight/Internal Testingで長期ベータテスト

**リスク4: React Native学習曲線**
- 対策: Week 1でReact Native基礎学習時間を確保
- 代替案: Expo公式ドキュメントとチュートリアルを活用

### スケジュールリスク

**リスク5: 開発遅延**
- 対策: 週次で進捗確認、早期に問題を検知
- 代替案: Phase 3の一部機能を後回し

**リスク6: テスト不足**
- 対策: 各Phaseでテストを実施
- 代替案: Phase 4を1週間延長
